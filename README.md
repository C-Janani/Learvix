# Learvix 🎓
## Personalized Learning Copilot for Core Courses

Learvix is a web-based learning platform designed to support students in learning core academic subjects through a structured and personalized learning flow. The project focuses on providing a clean user interface, topic-based learning entry, and a foundation for future AI-powered features.

---

## 📌 Project Overview
Learvix helps learners enter a topic of interest and guides them through a learning journey that can be enhanced with quizzes, performance tracking, and adaptive recommendations. This repository currently represents the frontend structure of the application.

---

## 🧩 Pages & Flow
- **index.html** – Login / entry page of the application  
- **home.html** – Home page after login with navigation  
- **learvix.html** – Main learning dashboard where users enter topics and begin learning  

---

## 🚀 Features
- Structured multi-page web application
- Topic-based learning input
- Modern UI with Tailwind CSS
- Animated and responsive design
- Beginner-friendly project structure

---

## 🛠️ Technologies Used
- HTML5  
- Tailwind CSS  
- JavaScript (planned)  

---

## ▶️ How to Run the Project
1. Clone or download the repository
2. Open `index.html` in any modern web browser
3. Navigate through the pages to explore the Learvix interface
