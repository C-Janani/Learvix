# Learvix 🎓
### Personalized Learning Copilot for Core Courses

Learvix is a web-based learning platform designed to help students learn core subjects through personalized topic selection, quizzes, and adaptive learning support.

---

## 🚀 Features
- Topic-based learning input
- Clean and modern UI
- Animated background for better user experience
- Built using HTML and Tailwind CSS
- Beginner-friendly project structure

---

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS
- JavaScript (future enhancement)

## ▶️ How to Run the Project
1. Download or clone the repository
2. Open `index.html` in any web browser
3. Enter a topic and explore the interface
